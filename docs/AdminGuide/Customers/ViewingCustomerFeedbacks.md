# Viewing Customer Feedbacks
To view the feedback received from the customers, navigate to **Customer** > **Feedbacks**. The following screen appears that displays all the feedbacks from the customers:![Feedbacks](img/Feedbacks.png)
- To download all the feedbacks in a .CSV format, click the **Download Report** button.
- To view the individual feedback in a new window, click the **View Review** button.
