# Adding a Role

To add a role, follow these steps:
1. Navigate to **Administration** > **Roles & Permissions**. The following screen appears, which lists all the existing roles and the associated permissions.![Edit Role](img/AddRole1.png)
2. Click on the **Add New Role** button. The following screen appears:![Edit Role](img/AddRole2.png)
3. Enter the **Role Name** and **Code**.
	:::note
	The unique Code must comprise of two uppercase alphabets.
	:::
1. Select all the permissions you want to associate with the role.
2. Click **Save**.
